The failure is loud. The cause is quiet.

In a multi-agent run, the last bad event is rarely the first bad decision.

Agents branch into parallel work, merge their results, and pass values between each other. A fallback in one agent becomes an input to another, then travels through a merge, a tool call, and three handoffs before it surfaces.

Ordinary traces show that sequence as a flat list. They don't tell you which upstream value changed the outcome, which branch introduced it, or whether two branches only failed together.

  • Branches split one run into parallel histories that no single log line connects.
  • Values travel. A default, a memory write, or a tool result can contaminate every later agent.
  • Failures surface late. The error you see is often downstream of the cause you need.

One capture. Four ways to find the cause.

Agent-Causality turns the run into a causal event graph, then works backward from failure with evidence instead of guesses.

Event graph recording

Events are stored with explicit causal parents, declared at capture time rather than inferred later.

tool read → LLM call · coarse → merge
field-level provenance / exact where possible

Value provenance tracing

Trace a value back through tools, memory, and handoffs; LLM-mediated links are clearly marked coarse.

Failure attribution

See whether a failure came from one branch, several branches, or the interaction between them.

Divergence detection

Decision baselines show where a branch diverged. Replay tests which input flipped the outcome.

Built for agent failures.

Three moments when a flat trace stops being enough.

Debug a failed agent pipeline

Incident response. A refund run ends in an audit failure. Start at the terminal event and walk back to the fallback that changed the outcome.

Audit which agent produced a bad value

Data audit. Ask where a score, status, or policy flag came from, and get the tool read, memory write, or fallback that produced it.

Compare a run against its baseline

Regression review. Line up a captured run with its decision contract and replayed variants to see where the path diverged.

Your first causal graph.

Install both packages for live OpenCode capture, then launch the explorer. The bundled demo trace loads locally, with no API key.

Python 3.11+ OpenCode 1.19+ AGPL-3.0

The Python package ships the SDK, CLI, ingest receiver, and explorer. The npm package is the OpenCode capture plugin. Live capture needs both.

SHELL / AGENT-CAUSALITY 
$ pip install agent-causality
$ opencode plugin add @psionic-labs/opencode-agent-causality
$ causality-explorer
→ http://127.0.0.1:8766
